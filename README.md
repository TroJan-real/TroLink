# 🇺🇸 English

## 📖 Overview

TroLink is a modern Discord ↔ Minecraft account linking plugin designed for Paper servers.

It allows players to securely connect their Discord accounts with their Minecraft profiles while providing role synchronization, nickname synchronization, verification rewards and seamless integration with popular server plugins.

Built with performance, reliability and simplicity in mind.

---

## ✨ Features

### 🔗 Account Linking

Securely link Discord accounts with Minecraft players.

### 🎭 Automatic Role Synchronization

Automatically synchronize Discord roles with Minecraft permissions.

### 🏷️ Nickname Synchronization

Keep Discord nicknames synchronized with Minecraft usernames.

### 🎁 Verification Rewards

Reward players after successful account verification.

### 💾 SQLite Storage

Reliable local database storage.

### ⚡ HikariCP Connection Pooling

Fast and optimized database performance.

### 🔌 PlaceholderAPI Support

Display linked account information using placeholders.

### 🛡️ Vault Integration

Extended compatibility with your server ecosystem.

### 🔄 Automatic Synchronization

Background tasks ensure account data remains synchronized.

---

## 🚀 Installation

### 1. Download

Download the latest release from GitHub Releases.

### 2. Install

Place the plugin inside your server's:

```text
/plugins
```

folder.

### 3. Configure

Start your server once and configure the generated files.

### 4. Discord Setup

Enter your Discord bot token and server information.

### 5. Restart

Restart your server and enjoy.
